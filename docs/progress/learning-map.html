How To Use This Map​

If you're working through Karpathy (building): Fill gaps in Levels 1-3 as you go. Write the page after you build the thing.

If you're reading Chip Huyen (studying): Fill gaps in Levels 5-7. Write the page after the chapter clicks.

General rule: Don't write pages preemptively. Build or read something, notice you can now explain it, write the page, check it off here.
