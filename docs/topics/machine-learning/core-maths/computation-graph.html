Computation Graphs: Forward and Backward

What is a Computation Graph?​

A computation graph is a way to break complex math into small, traceable steps. Each step becomes a node. It helps us:

  • See how data flows through a function (forward pass)
  • Trace how gradients flow back through the function (backward pass)
  • Understand backpropagation — the algorithm that trains neural networks

Every neural network framework (PyTorch, TensorFlow) builds a computation graph behind the scenes. When you call .backward() in PyTorch, it's walking backward through this graph.

Example Function​

J(a,b,c)=3(a+bc)J(a, b, c) = 3(a + bc)J(a,b,c)=3(a+bc)

We break this into intermediate steps:

u = b * c
v = a + u
J = 3 * v

Each line is one node in the graph. The output of one feeds into the next.

Forward Pass: Computing the Output​

Given: a=5a = 5a=5, b=3b = 3b=3, c=2c = 2c=2

StepFormulaResult
1u=b×cu = b \times cu=b×cu=3×2=6u = 3 \times 2 = 6u=3×2=6
2v=a+uv = a + uv=a+uv=5+6=11v = 5 + 6 = 11v=5+6=11
3J=3×vJ = 3 \times vJ=3×vJ=3×11=33J = 3 \times 11 = 33J=3×11=33

The graph looks like this:

   a = 5     b = 3      c = 2
     |          |          |
     |          +----+-----+
     |               |
     |          [ u = b * c ] --> u = 6
     |               |
     +-------+-------+
             |
        [ v = a + u ] --> v = 11
             |
        [ J = 3 * v ] --> J = 33

The forward pass computes the output. But by itself, it doesn't help the model learn. For that, we need the backward pass.

Backward Pass: Computing Gradients​

The backward pass answers: "If I change each input a little, how much does JJJ change?"

This is exactly what derivatives measure. The backward pass computes them efficiently using the chain rule — working from the output back to the inputs.

Step 1: How does JJJ change with vvv?​

J=3vJ = 3vJ=3v, so ∂J∂v=3\frac{\partial J}{\partial v} = 3∂v∂J​=3

If vvv increases by 1, JJJ increases by 3.

Step 2: How does JJJ change with aaa?​

v=a+uv = a + uv=a+u, so ∂v∂a=1\frac{\partial v}{\partial a} = 1∂a∂v​=1

By the chain rule: ∂J∂a=∂J∂v⋅∂v∂a=3×1=3\frac{\partial J}{\partial a} = \frac{\partial J}{\partial v} \cdot \frac{\partial v}{\partial a} = 3 \times 1 = 3∂a∂J​=∂v∂J​⋅∂a∂v​=3×1=3

Step 3: How does JJJ change with uuu?​

v=a+uv = a + uv=a+u, so ∂v∂u=1\frac{\partial v}{\partial u} = 1∂u∂v​=1

∂J∂u=∂J∂v⋅∂v∂u=3×1=3\frac{\partial J}{\partial u} = \frac{\partial J}{\partial v} \cdot \frac{\partial v}{\partial u} = 3 \times 1 = 3∂u∂J​=∂v∂J​⋅∂u∂v​=3×1=3

Step 4: How does JJJ change with bbb?​

u=bcu = bcu=bc, so ∂u∂b=c=2\frac{\partial u}{\partial b} = c = 2∂b∂u​=c=2

∂J∂b=∂J∂u⋅∂u∂b=3×2=6\frac{\partial J}{\partial b} = \frac{\partial J}{\partial u} \cdot \frac{\partial u}{\partial b} = 3 \times 2 = 6∂b∂J​=∂u∂J​⋅∂b∂u​=3×2=6

Step 5: How does JJJ change with ccc?​

u=bcu = bcu=bc, so ∂u∂c=b=3\frac{\partial u}{\partial c} = b = 3∂c∂u​=b=3

∂J∂c=∂J∂u⋅∂u∂c=3×3=9\frac{\partial J}{\partial c} = \frac{\partial J}{\partial u} \cdot \frac{\partial u}{\partial c} = 3 \times 3 = 9∂c∂J​=∂u∂J​⋅∂c∂u​=3×3=9

The Full Picture​

FORWARD (left to right):
   a=5  b=3  c=2  -->  u=6  -->  v=11  -->  J=33

BACKWARD (right to left):
   dJ/da=3  dJ/db=6  dJ/dc=9  <--  dJ/du=3  <--  dJ/dv=3  <--  dJ/dJ=1
VariableGradient (∂J∂⋅\frac{\partial J}{\partial \cdot}∂⋅∂J​)Meaning
vvv3Increasing vvv by 1 increases JJJ by 3
aaa3Increasing aaa by 1 increases JJJ by 3
uuu3Increasing uuu by 1 increases JJJ by 3
bbb6Increasing bbb by 1 increases JJJ by 6
ccc9Increasing ccc by 1 increases JJJ by 9

ccc has the largest gradient, meaning JJJ is most sensitive to changes in ccc. If these were model weights and JJJ were a loss function, gradient descent would adjust ccc the most.

Why This Matters for Neural Networks​

In a real neural network:

  • JJJ is the loss function (how wrong the model is)
  • aaa, bbb, ccc are weights and biases (the parameters being learned)
  • The forward pass computes the prediction and loss
  • The backward pass computes the gradient of the loss with respect to every weight
  • Gradient descent uses those gradients to update the weights: wnew=wold−α⋅∂J∂ww_{\text{new}} = w_{\text{old}} - \alpha \cdot \frac{\partial J}{\partial w}wnew​=wold​−α⋅∂w∂J​

This is what people mean when they say "backpropagation" — it's just the chain rule applied to a computation graph, one node at a time, from output back to inputs.

Summary​

ConceptWhat it does
Computation graphBreaks a function into small steps (nodes)
Forward passComputes the output by walking left-to-right
Backward passComputes gradients by walking right-to-left using the chain rule
Chain ruleMultiplies local derivatives along the path from output to input
Why it mattersThis is how every neural network learns — compute loss forward, compute gradients backward, update weights
